# Backend — FastAPI

Backend do DescompliADS.

Responsabilidades:

- API REST;
- regras de negócio;
- consolidação de métricas;
- comparação de períodos;
- acesso ao Supabase;
- preparação de respostas para o frontend.

A API fica em `app/api/`.

A documentação da Fase 1 fica em `../docs/fases/fase-1-backend.md`.
