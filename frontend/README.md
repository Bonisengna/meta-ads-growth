# Frontend — Next.js

Área reservada para a Fase 6 do MVP.

O frontend deverá consumir a API FastAPI e concentrar:

- dashboard;
- clientes;
- campanhas;
- análises;
- melhorias;
- filtros e gráficos;
- configurações.

A implementação Next.js será iniciada somente depois que o modelo de dados e os contratos principais da API estiverem estáveis.
