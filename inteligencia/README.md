# Inteligência

Área reservada para a Fase 7 e para a evolução analítica do DescompliADS.

Princípio:

- código calcula métricas, comparações, scores e regras determinísticas;
- IA interpreta resultados, explica causas prováveis, prioriza e propõe hipóteses;
- decisões críticas não dependem apenas do modelo de linguagem.

Aqui ficarão serviços, contratos e documentação específicos da camada de inteligência do SaaS.
