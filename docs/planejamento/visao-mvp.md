# Planejamento do MVP

O DescompliADS será um painel de inteligência para gestores de tráfego, focado inicialmente em Meta Ads.

Objetivo central:

```text
MÉTRICAS
   ↓
DIAGNÓSTICO
   ↓
RECOMENDAÇÃO
   ↓
MELHORIA
   ↓
VALIDAÇÃO
   ↓
APRENDIZADO
```

O MVP não é CRM, não substitui o Gerenciador de Anúncios e não fará operação direta de campanhas na primeira versão.

Roadmap:

1. Backend base.
2. Supabase.
3. Modelo de dados.
4. Integração dos dados existentes.
5. API do dashboard.
6. Frontend Next.js.
7. Inteligência.
8. Melhorias e aprendizado.
